# Changelog

All notable public-package changes are recorded here. The project uses semantic
versioning while remaining pre-1.0 and experimental.

## Unreleased

No changes yet.

## 0.1.0 — 2026-09-10

- Added the provider-independent `OptionState`, `FrozenOptionModel`,
  `OptionEdge` and `OptionNetwork` contract.
- Added explicit M0/M1 evaluation, model comparison and frozen network summaries.
- Added optional Kloppy interoperability and pandas export.
- Added mplsoccer/Matplotlib plotting and deterministic Pillow GIF examples.
- Documented the experimental API and its scientific limitations.

Version `0.1.0` is the first experimental public GitHub release. PyPI
publication is deferred.
