## Executable evidence boundary (prospective)

The complete handoff above is the frozen specification. The runner is
`scripts/session_14an_retained_evidence_adjudication.py`, with only preflight,
review and publication-check, launched with `uv run --locked python`.
An exclusive persistent review marker forbids automatic rerun, including failure.

Public inputs are exactly the 14am manifest and its listed public outputs.
Documentary inputs are the starting commit's governance, claim/competition
records, R8 and 14am reports/protocols, and source files named below.
The private index may be decoded as filename/hash metadata only; selected files
are hash-verified before lexical field projection. No source population, prepared
file, original R8 journal, selected_geometry, structure, onset_neighborhood,
access journal or scientific product may be opened. Other private files are not
opened even for hash verification.

Allowed private label -> projected fields (all other values skipped lexically):

- controlled_vector: intervals, estimates.maximum, change.
- strict/repeat: lower, upper, residual_bound, pieces, quadrature_pieces, bounded_pieces.
- onset_adaptive: estimate.
- actual_gate_inputs: condition, reason (not partitions or values).
- piecewise/uniform: intervals, estimate, successive_difference, seconds, evaluations
  (never contributions).
- independent_comparisons: health flags, production_difference, unsplit_difference
  (exact differences private).
- reproduction: reproduced, stage, calls, durations, inclusive_wall, inclusive_cpu;
  adaptive_returns: epsabs, epsrel, limit, estimate, reported_error only, never a/b.
- journal_metadata: records, bytes (not actions or identifiers).
- timeout: exception and partial_operation counts/timings/calls/completion; no traceback.
- retained_failure: original.exception and emergency.publication_exception only;
  free-text exceptions are reduced to presence, not published.

Evidence arithmetic is limited to finite-value validation, comparisons of already
retained deltas with frozen criteria, and consistency/count checks. No historical
gate function is invoked; no integral is recomputed. Exact diagnostic estimates
remain private. A missing projected field is unavailable, never synthesized.
The reviewer uses the standard library only, loaded without package-root imports.

Classification predicates are evaluated from explicit supported/unsupported/
unavailable findings. More than one independently established numerical mechanism
yields G; missing mechanism evidence yields H/readiness 4. Publication P1 requires
retained successful triangular-prefix controls plus documentary prefix replay;
missing historical-shape completion is retained separately. The minimal prospective
shape is elimination of repeated prefix reconstruction through chronological
single-pass state updates, only if supported; final-only validation is not equivalent.
No repair is authorized or executed by this review.

All thirteen output schemas have schema_version=1, fixed filenames and exact
field sets; each health output has status, checks, limitations and evidence refs.
Checks use true/false/null; null means unavailable. QC binds classification,
execution validity, zero geometry access and zero new adjudication numerics.
Manifest binds protocol/implementation/environment, source hashes, selected
evidence hashes and every closed output. Failures preserve an independent private
record and invalid package when possible; no successful acceptance is synthesized.
