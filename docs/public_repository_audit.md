## Outcome

The repository already had a strong protected receiver-ranking result, a tested
experimental package, a public prerelease, deterministic examples and unusually
complete governance. Its landing page did not yet connect those assets to the
major Session 13 advance: one defender can relate geometrically to several
attacking edges, while receiver pressure and corridor proximity are often
different relationships. It also stopped its public research narrative before
the current continuous-field question.

The README now begins with football as interacting spatial options and identifies
the supported object as a local carrier-centred star. It separates established
evidence, the current hypothesis, conditional future work, package use and
limitations. Public index and current-status documents now point to the same
frontier without rewriting historical evidence.

  paired consistency and limitations are committed and traceable.

  rather than implying a validated whole-team graph.

  API, optional Kloppy/pandas/visualization workflows, CI and tested archives.

  exist; multi-edge defender geometry recurs across development states.

  describe that structure beyond isotropic proximity, followed by separately

  weighting, pose/orientation and links to defensive reallocation work.

validated whole-team graph.
