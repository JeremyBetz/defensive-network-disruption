# Notebooks

No analysis notebook is created before its protocol and data partition exist.
Use phase-prefixed descriptive names later, and state protocol/version, purpose,
data release and partition, exposure status, and reproduction command at the top.

Keep reusable logic in `src/defensive_network_disruption/`. Clear execution counts
and outputs before committing; inspect source cells, attachments, and embedded
images for competition records as well. Persist full local execution artifacts
under ignored `outputs/` and record all outcomes in the research log.

Do not execute library demonstration notebooks that download other providers'
data. A readable pitch plot can diagnose code, but does not validate an edge.
